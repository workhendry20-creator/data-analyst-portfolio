# Sales Data Analysis

This project analyzes sales transaction data using Python and Google Colab.  
The goal is to identify top-performing product categories, clean the dataset, visualize sales performance, and generate simple business insights.

## Tools
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis
- Data loading
- Missing value checking
- Duplicate removal
- Sales analysis by product line
- Data visualization

## Key Insights
- Classic Cars generated the highest total sales.
- Vintage Cars ranked second in total sales.
- Trains had the lowest sales contribution.
- Product category performance can help support business decision-making.
